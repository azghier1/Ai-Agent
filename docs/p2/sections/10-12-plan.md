## 10.4 Repository

URL: https://github.com/azghier1/Ai-Agent (public).

Layout: `/docs/p2` holds this PDF and the source of each section in `/docs/p2/sections`; `/docs/p2/diagrams` holds every diagram's source file and exported image; `/spikes` holds the architecture spike with its README and measurements; the prototype code is at the repository root (`agent.py`, `lms.py`, `server.py`, `web/`, `docker-compose.yml`, `moodle/`).

Rules: `main` holds only reviewed work. Each change is made on its own branch named `type/short-description` and merged through a pull request that another member approves. Commit messages start with the section or requirement they change (for example `6.3: add component view`). Credentials stay in a local `.env` file that is excluded from the repository.

The tag `p2` points at the commit that contains this PDF.
